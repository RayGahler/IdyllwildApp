# Open this project in Qt Creator

1. Extract `IdyllwildApp-v13-QtCreator.zip` to a writable folder.
2. In Qt Creator, choose **File → Open File or Project**.
3. Select `IdyllwildApp-v13/CMakeLists.txt` (inside the extracted folder).
4. Choose a Qt kit with Qt Widgets, Network, and Multimedia installed, then configure and build.

This is a CMake project. Open the extracted folder's `CMakeLists.txt`; Qt Creator cannot open the ZIP archive directly.
